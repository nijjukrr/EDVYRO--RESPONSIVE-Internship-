Frequently Asked Questions

Platform Architecture & Usage

How are internship listings loaded?

When running locally with the Express server, listings load directly from the persistent SQLite database via GET /api/internships. On GitHub Pages static hosting, listings load directly from the verified static dataset.

How is application submission protected?

Submissions pass client-side and server-side schema checks, parameterized SQLite inserts, duplicate application constraints per role and email, Helmet security headers, and rate limiting on POST /api/applications.

Why does GitHub Pages show Static Demo Mode on submit?

GitHub Pages serves static files only and cannot run Node.js or SQLite. Instead of faking a confirmation receipt, the portal explains how to submit real applications using the local Express API.

Can I apply to multiple different internships?

Yes. Duplicate prevention blocks applying more than once to the same internship ID with the same normalized email, while allowing applications across different internship roles.
